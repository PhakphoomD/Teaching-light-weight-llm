STAGE.PY - StudentStage Class:
-------------------------------
class StudentStage:
    Dependencies (passed in __init__):
    - config: Dict[str, Any]
    - student_client: LLM client (LocalClient/GeminiClient/GroqClient)
    - memory_store: MemoryStore instance
    - vector_index: VectorIndex instance
    
    Plugins (lazy-loaded):
    - memory_retrieval: MemoryRetrievalPlugin
    - generator: GeneratorPlugin
    
    Main method: process(question, hints, iteration, previous_answer)
    Returns: {answer, context_used, context_ids, tokens, latency}


PLUGIN 1: GeneratorPlugin (generator.py)
-----------------------------------------
Purpose: Generate answer using LLM
Input: prompt (string)
Output: {answer, tokens, latency}
LLM Client: Injected in __init__
Settings: temperature, max_tokens from SETTINGS

Flow:
1. Get temperature/max_tokens from SETTINGS.student
2. Call student_client.chat(prompt, temp, tokens)
3. Extract answer from response
4. Return with metadata

⚠️ NOT pluggable to different generators - uses injected client


PLUGIN 2: MemoryRetrievalPlugin (memory_retrieval.py)
------------------------------------------------------
Purpose: Retrieve similar past attempts from memory
Input: question, task, structure, params
Output: List of memory records (top-k)
Dependencies: memory_store, vector_index (injected)

Flow:
1. Route question → (task, structure) via TaskClassifier
2. Build structure_tokens: "task | structure | params"
3. Embed structure_tokens using VectorIndex
4. Search FAISS index (k=3 by default)
5. Filter by similarity_threshold (0.5)
6. Load full records from MemoryStore
7. Return records

⚠️ Routing logic in TaskClassifier (src/memory/plugins/task_classifier.py)


STUDENT PROMPT BUILDING (src/prompts/student.py):
--------------------------------------------------
Function: build_student_prompt(question, hints, context, previous_answer)

Two modes:
1. First attempt (iteration=1):
   "Answer the following question directly and completely."
   [Question]
   ⚠️ Context DISABLED (commented out lines 101-107)

2. Refinement (iteration 2+):
   "You are refining your answer. Provide a clear, complete response."
   "Your previous answer was: [previous_answer]"
   "Feedback: [hints joined]"
   [Question]

⚠️ memory context ถูก disable เพื่อป้องกัน TinyLlama สับสน

✅ No imports from memory/ (except via shared plugins)
✅ Communication via simple types (str, List[str], Dict)
✅ Plugins injected via dependency injection

STAGE.PY - TeacherStage Class:
-------------------------------
class TeacherStage:
    Dependencies (passed in __init__):
    - config: Dict[str, Any]
    - critic: HybridCritic or TeacherCritic instance
    
    Plugins (lazy-loaded):
    - evaluator: EvaluatorPlugin
    - early_stopping: EarlyStoppingPlugin
    
    Main method: process(question, student_answer, correct_answer, iteration)
    Returns: {is_correct, evaluation, reasoning, hint, stop_score, should_stop, error_keys}


PLUGIN 1: EvaluatorPlugin (evaluator.py)
-----------------------------------------
Purpose: Evaluate + generate hint (COMBINED!)
Input: question, answer, ground_truth, use_cot
Output: Complete evaluation dict with hint
Critic: Injected in __init__ (HybridCritic or TeacherCritic)

Flow:
1. Call critic.evaluate() → CriticFeedback
2. Build reasoning from issues
3. ⭐ BUILD HINT (lines 117-135):
   Format:
   "Your answer has issues:
     1. [issue1]
     2. [issue2]
    How to improve:
     - [fix1]
     - [fix2]"
4. Filter leakage using hint_generator.py
5. Truncate if > hint_max_length (500 chars)
6. Return full evaluation dict

⚠️ This is where hints are formatted!


PLUGIN 2: HybridCritic (aggregator.py)
---------------------------------------
Purpose: Combine rule-based + LLM evaluation
Input: question, answer, ground_truth, use_cot
Output: CriticFeedback (issues, fixes, lesson, scores, error_keys)

Components:
- RuleCheckers: Fast heuristics (F1, overlap, length, punctuation)
- LLMEvaluator: Deep reasoning (optional, if enabled)
- Calibration: sigmoid(a*score + b) → stop_score

Flow:
1. Run rule checkers → {rule_score, error_keys}
2. If LLM enabled → Run LLM evaluator → {issues, fixes, lesson}
3. Merge feedback:
   - If LLM available: Use LLM's fixes (filtered for leakage)
   - If LLM unavailable: ⭐ MAP error_keys to readable hints:
     ```python
     if key == "wrong_answer":
         fixes.append("Your answer is incorrect. Please reconsider...")
     elif key == "no_punctuation":
         fixes.append("Add proper punctuation...")
     elif key == "low_overlap":
         fixes.append("Doesn't match expected content...")
     # ... more mappings
     ```
4. Calibrate stop_score
5. Return CriticFeedback


PLUGIN 3: LLMEvaluator (llm_evaluator.py)
------------------------------------------
Purpose: Use LLM for deep evaluation
Input: question, answer, ground_truth, error_keys
Output: {issues, fixes, lesson, scores}
LLM Client: Initialized in __init__ (Gemini/Groq)

Flow:
1. Build evaluation prompt with CoT
2. Call LLM with structured output
3. Parse JSON response
4. Return feedback

⚠️ Dapat disabled (llm_reviewer.enabled: false) ตอนนี้เพราะ quota


PLUGIN 4: RuleCheckers (rule_checkers.py)
------------------------------------------
Purpose: Fast heuristic checks
Functions:
- check_exact_match()
- check_token_overlap() - F1 score
- check_length()
- check_punctuation()
- check_empty()

Each returns: {passed: bool, score: float, error_key: str}

Combined in run_all_checks() → aggregated score + error_keys


PLUGIN 5: EarlyStoppingPlugin (early_stopping.py)
--------------------------------------------------
Purpose: Decide when to stop refinement
Input: stop_score, iteration
Output: should_stop (bool)

Algorithm:
- Track stop_scores across rounds
- Check if no improvement for patience=2 rounds
- Check if gain < epsilon_gain (0.01)
- Check if iteration >= patience

⚠️ Only used for INCORRECT answers (correct = immediate stop)


TEACHER STAGE INDEPENDENCE CHECK:
----------------------------------
✅ No imports from student/
✅ No imports from memory/
✅ HybridCritic can be swapped with TeacherCritic
✅ LLM client injected (not hardcoded)
✅ All plugins lazy-loaded
✅ Communication via CriticFeedback dataclass

STAGE.PY - MemoryStage Class:

class MemoryStage:

    Plugins (lazy-loaded):
    - storage: StoragePlugin
    - logger: LoggerPlugin
    
    Main method: process(question, answer, evaluation, exp_id, q_id, round)
    Returns: None (side effects: writes to disk)


PLUGIN 1: StoragePlugin (storage.py)
-------------------------------------
Purpose: Store incorrect attempts to memory
Input: question, answer, evaluation, metadata
Output: None (writes to JSONL + FAISS)
Dependencies: memory_store, vector_index (injected)

Flow (only if answer INCORRECT):
1. Route question → (task, structure, params) via TaskClassifier
2. Create compact record:
   - question, answer, feedback (hint)
   - task, structure, params
   - timestamp, score, round_num
3. Save to MemoryStore (JSONL file)
4. Build structure_tokens: "task | structure | params"
5. Embed using VectorIndex.encoder
6. Add to FAISS index
7. Save index to disk

⚠️ Correct answers are NOT stored


PLUGIN 2: LoggerPlugin (logger.py)
-----------------------------------
Purpose: Log detailed iteration info (optional)
Input: Full round data
Output: None (writes to JSON file)

⚠️ Currently minimal - just logs to file


SHARED PLUGIN: TaskClassifier (task_classifier.py)
---------------------------------------------------
Location: src/memory/plugins/task_classifier.py
Used by: BOTH StudentStage (retrieval) and MemoryStage (storage)

Purpose: Route question → (task, structure, params)

Tasks:
- general_instruction
- list_generation (with n=X)
- classification
- definition
- translation
- text_splitting
- calculation (unused)

Structures:
- general
- list(n)
- classify
- definition_short/definition_long
- translate
- split_sentences/split_words

⚠️ This is SHARED between stages but independent (pure function)


SHARED PLUGIN: MemoryStore (store.py)
--------------------------------------
Location: src/refinement/memory/plugins/store.py
Used by: BOTH StudentStage and MemoryStage

Purpose: JSONL file storage for records

Methods:
- save_record(record) → Append to JSONL
- load_records() → Read all records
- get_record(id) → Get specific record

⚠️ Simple JSONL append-only storage


SHARED PLUGIN: VectorIndex (vector_index.py)
---------------------------------------------
Location: src/refinement/memory/plugins/vector_index.py
Used by: BOTH StudentStage and MemoryStage

Purpose: FAISS vector similarity search

Components:
- SentenceTransformer: all-MiniLM-L6-v2 (384-dim)
- FAISS IndexFlatIP: Inner product (cosine similarity)

Methods:
- add_record(id, text) → Embed + add to index
- retrieve(query, k) → Top-k similar records
- save()/load() → Persist to disk

⚠️ Embeddings are L2-normalized for cosine similarity

PLUGIN PATTERN USED:
--------------------
✅ Lazy loading: Plugins loaded only when needed
✅ Dependency injection: External dependencies passed to plugins
✅ Single responsibility: Each plugin does ONE thing
✅ Pluggable: Can swap implementations without changing stage


PLUGIN LOADING MECHANISM:
--------------------------
Each Stage has:
```python
def _load_plugin(self, plugin_name: str):
    if plugin_name not in self.loaded_plugins:
        # Import and instantiate
        from .plugins.xxx import XxxPlugin
        self.loaded_plugins[plugin_name] = XxxPlugin(dependencies)
    return self.loaded_plugins[plugin_name]
```

Benefits:
- No circular imports
- Only load what's used
- Easy to test individual plugins
- Can mock plugins for testing

│   └── Return CriticFeedback

├── Build hint from CriticFeedback:

│     1. Missing punctuation

├── Check if correct: stop_score=0.73 >= 0.7 → is_correct=True
