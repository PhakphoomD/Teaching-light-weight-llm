## 💡 Solution: **"Incremental Consolidation"**

### **แนวคิด:**
**แทนที่จะเก็บ mini-summary แยก** → **ให้ consolidate (รวม) ทุกครั้งที่ถามซ้ำ**

```python
# แทนที่จะเก็บ 3 records แยก:
Record 1: "Confused countries - said Thailand"
Record 2: "Incomplete - didn't mention location"  
Record 3: "Too vague - said Europe not France"

# ให้เก็บ 1 record ที่ UPDATE ต่อเนื่อง:
Record (consolidated): 
"Tried 3 times: confused country (Thailand), then incomplete (no location), then vague (Europe). Focus on specific city in France."
```

## 🛠️ Implementation: **Question-based Deduplication + Consolidation**

### **Step 1: ใช้ question vector เป็น unique key**

```python
def get_or_create_memory_record(question):
    """
    Check if question exists in memory
    If yes: return existing record
    If no: create new record
    """
    question_hash = hash_question_vector(question)
    
    existing_record = memory_store.get_by_id(question_hash)
    
    if existing_record:
        return existing_record, "existing"
    else:
        new_record = {
            "id": question_hash,
            "question": question,
            "attempts": [],  # ← Track all attempts!
            "consolidated_summary": ""
        }
        return new_record, "new"
```

### **Step 2: เก็บ attempts เป็น list แล้ว consolidate**

```python
def store_memory_with_consolidation(question, answer, feedback, teacher):
    """
    Store OR update memory with consolidation
    """
    record, status = get_or_create_memory_record(question)
    
    # Add new attempt
    attempt = {
        "round": len(record["attempts"]) + 1,
        "answer": answer,
        "feedback": feedback,
        "primary_error": categorize_feedback(feedback),
        "timestamp": datetime.now().isoformat()
    }
    record["attempts"].append(attempt)
    
    # Consolidate only if multiple attempts (2+)
    if len(record["attempts"]) >= 2:
        # Teacher creates ONE consolidated summary from ALL attempts
        record["consolidated_summary"] = teacher.consolidate_mistakes(
            question=question,
            attempts=record["attempts"],
            max_tokens=30  # Still short!
        )
        
        logger.info(f"Consolidated {len(record['attempts'])} attempts into summary")
    else:
        # First attempt: just use mini-summary
        record["consolidated_summary"] = attempt["feedback"][:50]
    
    # Save/update
    memory_store.save(record)
```

### **Step 3: Consolidation prompt ให้ teacher**

```python
def consolidate_mistakes(question, attempts, max_tokens=30):
    """
    Teacher consolidates multiple attempts into ONE summary
    """
    prompt = f"""Question: {question}

Student made {len(attempts)} attempts with different mistakes:
"""
    for i, att in enumerate(attempts, 1):
        prompt += f"{i}. {att['primary_error']}: {att['feedback'][:50]}\n"
    
    prompt += f"""
Consolidate these mistakes into ONE brief summary (max {max_tokens} words).
Focus on the PATTERN, not individual mistakes.

Summary:"""
    
    response = teacher_client.generate(prompt, max_tokens=max_tokens)
    return response.strip()


# Example output:
# Input attempts:
#   1. wrong_concept: "Said Thailand instead of France"
#   2. incomplete: "Didn't mention specific location"  
#   3. vague: "Said Europe, too broad"
#
# Consolidated output:
# "Struggles with geographical specificity - needs to name France and city (Paris)"
```

### **Step 4: Student retrieves consolidated summary (1 line!)**

```python
def retrieve_for_student(question, k=3):
    """
    Retrieve consolidated summaries only
    """
    similar_questions = vector_index.search(question, k=k)
    
    summaries = []

            "summary": record["consolidated_summary"]  # ← ONE LINE
```

## 🔥 Advanced: **Consolidation Threshold**

```python
def store_memory_smart(question, answer, feedback, teacher):
    """
    Smart consolidation based on attempts
    """
    record, status = get_or_create_memory_record(question)
    
    # Add attempt
    record["attempts"].append({...})
    
    # Consolidate based on threshold
    num_attempts = len(record["attempts"])
    
    if num_attempts == 1:
        # First time: use mini-summary as-is
        record["consolidated_summary"] = mini_summarize(feedback)
    
    elif num_attempts == 2:
        # Second time: simple merge (cheap)
        record["consolidated_summary"] = f"Tried twice: {error1}, then {error2}"
    
    elif num_attempts >= 3:
        # Third+ time: teacher consolidation (expensive but worth it)
        record["consolidated_summary"] = teacher.consolidate_mistakes(
            question=question,
            attempts=record["attempts"]
        )
    
    memory_store.save(record)
```

```python
def generate_direct_teaching(question, student_answer, ground_truth, previous_teaching=None):
    """
    Teacher creates direct instruction
    """
    prompt = f"""You are a teacher. The student answered wrong.

Question: {question}
Student's answer: {student_answer}
Correct answer: {ground_truth}
"""
    
    if previous_teaching:
        prompt += f"""
Previous teaching: {previous_teaching}
(Student still got it wrong!)
"""
    
    prompt += """
Give DIRECT teaching instruction in Thai:
1. Explain what the correct answer is
2. End with "ตอบว่า: [correct answer]"

Keep it SHORT (max 2 sentences).

Teaching:"""
    
    response = teacher_client.generate(prompt, max_tokens=50)
    return response.strip()
```

### **Memory Storage (Dead Simple!):**
```python
def store_teaching_memory(question, student_answer, ground_truth, teacher):
    """
    Store or update teaching memory
    """
    # Check if question exists
    q_id = hash_question(question)
    existing = memory_store.get(q_id)
    
    if existing:
        # Update: Generate new teaching based on previous + new mistake
        new_teaching = teacher.generate_direct_teaching(
            question=question,
            student_answer=student_answer,
            ground_truth=ground_truth,
            previous_teaching=existing["teaching"]
        )
        
        existing["teaching"] = new_teaching
        existing["attempts"] += 1
        memory_store.save(existing)
    else:
        # New: Generate first teaching
        teaching = teacher.generate_direct_teaching(
            question=question,
            student_answer=student_answer,
            ground_truth=ground_truth
        )
        
        record = {
            "id": q_id,
            "question": question,
            "teaching": teaching,
            "attempts": 1,
            "timestamp": datetime.now().isoformat()
        }
        memory_store.save(record)
```

```python
def retrieve_teaching(question):
```

```python
Update the teaching to be MORE SPECIFIC. Keep it SHORT (max 30 words).

    else:
```

### **Step 2: Store/Update memory**
```python
def store_or_update_memory(question, answer, ground_truth, score, teacher_llm):
    """
    Store or update teaching prompt in memory
    """
    q_id = hash_question(question)
    existing = memory_store.get(q_id)
    
    if score >= 0.7:
        # Correct! No need to update
        if existing:
            existing["last_score"] = score
            existing["attempts"] += 1
            memory_store.save(existing)
        return None
    
    # Wrong answer - need teaching
    if existing:
        # Update teaching prompt
        new_teaching = generate_teaching_prompt(
            question=question,
            student_answer=answer,
            ground_truth=ground_truth,
            previous_prompt=existing["teaching_prompt"]
        )
        
        existing["teaching_prompt"] = new_teaching  # ← UPDATE!
        existing["attempts"] += 1
        existing["last_score"] = score
        memory_store.save(existing)
        
        return new_teaching
    else:
        # First time - create teaching
        teaching = generate_teaching_prompt(
            question=question,
            student_answer=answer,
            ground_truth=ground_truth,
            previous_prompt=None
        )
        
        record = {
            "id": q_id,
            "question": question,
            "teaching_prompt": teaching,  # ← NEW!
            "attempts": 1,
            "last_score": score,
            "timestamp": datetime.now().isoformat()
        }
        memory_store.save(record)
        
        return teaching
```

### **Step 3: Student retrieves teaching prompt**
```python
def build_student_prompt(question):

Teaching: {memory["teaching_prompt"]}

Answer:"""
    else:
        # No teaching (first time or was correct)
        prompt = f"""Question: {question}
```

## 🔧 Teacher Scoring (Simplified)

```python
def evaluate_answer(question, answer, ground_truth):
    """
    Teacher evaluates with weighted metrics (NO complex logic)
    """
    # Rule-based metrics (fast!)
    exact = 1.0 if answer.strip() == ground_truth.strip() else 0.0
    f1 = compute_f1_score(answer, ground_truth)
    bleu = compute_bleu_score(answer, ground_truth)
    
    # Weighted combination (prevent bias)
    score = 0.4 * exact + 0.3 * f1 + 0.3 * bleu
    
    # Optional: LLM check for borderline cases (0.4-0.7)
    if 0.4 <= score <= 0.7 and llm_available:
        llm_score = llm_quick_check(question, answer, ground_truth)
        score = 0.6 * score + 0.4 * llm_score
    
    return score
```

### **Step 1: Question Embedding as ID (Fast Retrieval)**

```python
from sentence_transformers import SentenceTransformer

encoder = SentenceTransformer('all-MiniLM-L6-v2')

def get_question_id(question: str) -> str:
    """
    Convert question to embedding, then to ID
    """
    # Embed question
    embedding = encoder.encode(question, normalize_embeddings=True)
    
    # Convert to bytes then hash for ID
    import hashlib
    embedding_bytes = embedding.tobytes()
    question_id = hashlib.sha256(embedding_bytes).hexdigest()[:16]
    
    return question_id


# Example:
q1_id = get_question_id("Separate: helloworld")
q2_id = get_question_id("Separate: goodmorning")

# Similar questions → similar IDs (can find via FAISS!)
```

```python
def retrieve_teaching(question, threshold=0.8, k=3):
    """
    Find similar questions and their principles
    """
    # Embed current question
    q_embedding = encoder.encode(question, normalize_embeddings=True)
    
    # Search FAISS for similar question embeddings
    similarities, indices = faiss_index.search(q_embedding, k=k)
    
    # Filter by threshold
    relevant = []
    for sim, idx in zip(similarities[0], indices[0]):
        if sim >= threshold:
            record_id = id_mapping[idx]
            record = memory_store.get(record_id)
            relevant.append({
                "similarity": sim,
                "question": record["question"],
                "principle": record["teaching_principle"]
            })
    
    return relevant
```

## 🔥 Deduplication Strategy

```python
def store_or_update_with_deduplication(question, answer, ground_truth, score, teacher):
    """
    Check if similar question exists before storing
    """
    # Search for very similar questions (threshold=0.95)
    similar = retrieve_teaching(question, threshold=0.95, k=1)
    
    if similar and similar[0]["similarity"] >= 0.95:
        # Almost identical question exists!
        existing_id = similar[0]["id"]
        existing = memory_store.get(existing_id)
        
        if score < 0.7:
            # Still wrong - update principle
            new_principle = generate_principle_teaching(
                question=question,
                answer=answer,
                ground_truth=ground_truth,
                previous_principle=existing["teaching_principle"]
            )
            existing["teaching_principle"] = new_principle
            existing["attempts"] += 1
        else:
            # Correct - just update metadata
            existing["attempts"] += 1
            existing["last_score"] = score
        
        memory_store.save(existing)
        return "updated"
    else:
        # New question - store with principle
        if score < 0.7:
            principle = generate_principle_teaching(
                question=question,
                answer=answer,
                ground_truth=ground_truth
            )
            
            q_embedding = encoder.encode(question)
            q_id = hash_embedding(q_embedding)
            
            record = {
                "id": q_id,
                "question_embedding": q_embedding.tolist(),
                "question": question,
                "teaching_principle": principle,
                "attempts": 1,
                "last_score": score
            }
            
            memory_store.save(record)
            faiss_index.add(q_embedding)
            
            return "created"
        else:
            return "skipped"  # Correct on first try
```

```python
def generate_meta_principle(question, answer, ground_truth, previous_principle=None):
    """

- 3-word compounds (howareyou → how are you)

    else:

Don't mention specific numbers (like "2 words" or "3 words").

Principle (max 30 words):"""
    
    principle = teacher_llm.generate(prompt, max_tokens=50)
```

## 🎯 Key Design Principles

### **1. Anti-Overfitting Check**

```python
def check_principle_overfitting(principle, new_question, student_answer, ground_truth):
    """
    Detect if principle is over-specific
    """
    # Check for specific numbers
    if any(word in principle.lower() for word in ["two", "three", "2", "3", "pair"]):
        return True, "Contains specific numbers"
    
    # Check if it works for different sizes
    correct_word_count = len(ground_truth.split())
    student_word_count = len(student_answer.split())
    
    if correct_word_count != student_word_count:
        # Student forced wrong number of words
        if f"{student_word_count} word" in principle.lower():
            return True, f"Principle mentions {student_word_count} words explicitly"
    
    return False, "Principle seems general"


# Usage:
is_overfit, reason = check_principle_overfitting(
    principle="Split compound into two separate words",
    new_question="Separate: howareyou",
    student_answer="howare you",
    ground_truth="how are you"
)

if is_overfit:
    logger.warning(f"⚠️ Overfitting detected: {reason}")
    # Force principle regeneration with "be more general" instruction
```

### **2. Principle Quality Scoring**

```python
def score_principle_quality(principle):
    """
    Score how general/robust a principle is
    """
    score = 1.0
    
    # Deductions for over-specific terms
    specific_terms = {
        "two": -0.3,
        "three": -0.3,
        "2": -0.3,
        "3": -0.3,
        "pair": -0.2,
        "couple": -0.2,
        "both": -0.2
    }
    
    for term, penalty in specific_terms.items():
        if term in principle.lower():
            score += penalty
            logger.debug(f"Penalty: '{term}' found → {penalty}")
    
    # Bonuses for generalizable terms
    general_terms = {
        "meaningful": +0.2,
        "identify": +0.1,
        "each": +0.1,
        "all": +0.2,
        "any": +0.1,
        "complete": +0.1,
        "dictionary": +0.2
    }
    
    for term, bonus in general_terms.items():
        if term in principle.lower():
            score += bonus
            logger.debug(f"Bonus: '{term}' found → +{bonus}")
    
    return max(0.0, min(1.0, score))


# Example:
p1 = "Split compound into two separate words"
score1 = score_principle_quality(p1)  # 0.7 (penalty for "two")

p2 = "Identify meaningful words in compound. Separate all of them."
score2 = score_principle_quality(p2)  # 1.0 (bonuses for "meaningful", "all")
```

### **3. Adaptive Refinement**

```python
def refine_principle_if_needed(principle, success_rate, attempts):
    """
    Automatically refine principle if success rate is low
    """
    if attempts >= 3 and success_rate < 0.6:
        # Principle isn't working well
        logger.warning(f"Principle success rate low: {success_rate:.2%} after {attempts} attempts")
        
        refinement_prompt = f"""This principle has low success rate ({success_rate:.2%}):

"{principle}"

Students keep making mistakes. The principle might be:
1. Too vague (missing important details)
2. Too specific (works for some cases, not others)
3. Unclear (students don't understand)

Rewrite it to be:
- More GENERAL (works for any number of words)
- More CLEAR (easy to understand)
- More ACTIONABLE (tells students what to do)

Improved principle:"""
        
        improved = teacher_llm.generate(refinement_prompt, max_tokens=50)
        return improved.strip()
    
    return principle  # No change needed
```

```python
class SimpleTeacher:
    """
    Teacher มี 2 หน้าที่หลัก:
    1. Score ด้วย metrics (rule-based: F1, BLEU, Exact Match)
    2. Generate/Refine feedback ด้วย LLM + COT
    """
    
    def evaluate(self, question, student_answer, ground_truth, previous_feedback=None):
        # ============================================
        # Part 1: SCORING (Fast, Deterministic)
        # ============================================
        score_result = self.compute_score(
            answer=student_answer,
            ground_truth=ground_truth
        )
        # score_result = {
        #   "overall": 0.65,
        #   "f1": 0.7,
        #   "bleu": 0.6,
        #   "exact": 0.0,
        #   "pass": False  # < 0.8 threshold
        # }
        
        # ============================================
        # Part 2: FEEDBACK GENERATION (LLM + COT)
        # ถ้า pass แล้ว ไม่ต้องสร้าง feedback
        # ============================================
        if score_result["pass"]:
            return {
                "score": score_result,
                "feedback": None,  # ไม่ต้องสร้าง
                "action": "pass"
            }
        
        # ถ้า fail → สร้าง/ปรับปรุง feedback
        if previous_feedback is None:
            # ครั้งแรกที่ fail → สร้าง feedback ใหม่
            feedback = self.generate_initial_feedback(
                question=question,
                student_answer=student_answer,
                ground_truth=ground_truth,
                score_result=score_result
            )
        else:
            # เคย fail มาแล้ว และมี feedback เก่า → ปรับปรุงด้วย COT
            feedback = self.refine_feedback_with_cot(
                question=question,
                student_answer=student_answer,
                ground_truth=ground_truth,
                previous_feedback=previous_feedback,
                score_result=score_result
            )
        
        return {
            "score": score_result,
            "feedback": feedback,
            "action": "retry"
        }
    
    
    # ============================================
    # SCORING METHODS (Rule-based, No LLM)
    # ============================================
    def compute_score(self, answer: str, ground_truth: str) -> dict:
        """
        คำนวณคะแนนด้วย metrics แบบ rule-based
        - F1 score (token overlap)
        - BLEU score (n-gram similarity)
        - Exact match (binary)
        - Weighted combination: 0.3*F1 + 0.3*BLEU + 0.4*Exact
        """
        from src.eval.metrics import compute_f1, compute_bleu
        
        # Compute individual metrics
        f1 = compute_f1(answer, ground_truth)
        bleu = compute_bleu(answer, ground_truth)
        exact = 1.0 if answer.strip().lower() == ground_truth.strip().lower() else 0.0
        
        # Weighted combination
        overall = 0.3 * f1 + 0.3 * bleu + 0.4 * exact
        
        # Pass/Fail threshold
        threshold = 0.8
        passed = overall >= threshold
        
        return {
            "overall": overall,
            "f1": f1,
            "bleu": bleu,
            "exact": exact,
            "pass": passed,
            "threshold": threshold
        }
    
    
    # ============================================
    # FEEDBACK GENERATION (LLM-based)
    # ============================================
    def generate_initial_feedback(
        self, 
        question: str, 
        student_answer: str, 
        ground_truth: str,
        score_result: dict
    ) -> str:
        """
        สร้าง feedback ครั้งแรก (ไม่มี COT ซับซ้อน)
        แค่บอกว่าผิดตรงไหน และควรทำอย่างไร
        """
        prompt = f"""
Question: {question}
Student's answer: {student_answer}
Correct answer: {ground_truth}

Score breakdown:
- F1: {score_result['f1']:.2f}
- BLEU: {score_result['bleu']:.2f}
- Exact match: {score_result['exact']:.2f}
- Overall: {score_result['overall']:.2f} (threshold: 0.8)

Provide clear, concise feedback to help student improve.
Focus on the CONCEPT, not just this specific answer.
Keep it general enough to apply to similar questions.

Feedback:"""
        
        return self.llm.call(prompt)
    
    
    def refine_feedback_with_cot(
        self,
        question: str,
        student_answer: str,
        ground_truth: str,
        previous_feedback: str,
        score_result: dict
    ) -> str:
        """
        ปรับปรุง feedback ด้วย COT เมื่อ student ยังตอบผิดอยู่
        วิเคราะห์ว่า feedback เก่าทำไมใช้ไม่ได้
        """
        cot_prompt = f"""
Previous feedback given: "{previous_feedback}"

New question: {question}
Student's latest answer: {student_answer}
Correct answer: {ground_truth}

Score breakdown:
- F1: {score_result['f1']:.2f}
- BLEU: {score_result['bleu']:.2f}
- Exact match: {score_result['exact']:.2f}
- Overall: {score_result['overall']:.2f} (threshold: 0.8)

<Chain-of-Thought>
1. What does this question require?
   [Analyze the question type and goal]

2. Why did the previous feedback fail?
   - Previous feedback: "{previous_feedback}"
   - Student still answered: {student_answer}
   - Analysis: [What went wrong?]

3. What's too specific in the old feedback?
   - [Identify overly specific parts]
   - Does it mention exact examples? Specific numbers?

4. How can we make it more general?
   - [Think about the PRINCIPLE that works for ALL similar questions]
   - What concept applies universally?

5. Improved feedback (general and actionable):
   [Write better feedback here]
</Chain-of-Thought>

Return ONLY the improved feedback (step 5).
Keep it short, clear, and GENERAL.
"""
        
        return self.llm.call(cot_prompt)
```

## 1. Retrieval Strategy (Embedding Similarity)

```python
class MemoryRetrieval:
    """
    ใช้ FAISS + Embedding similarity สำหรับ retrieve feedback
    """
    
    def __init__(self, embedding_model="all-MiniLM-L6-v2"):
        self.embedding_model = SentenceTransformer(embedding_model)
        self.index = faiss.IndexFlatIP()  # Inner Product (cosine similarity)
        self.memory_store = []  # List of feedback records
    
    
    def retrieve_for_student(self, question: str, top_k: int = 3, threshold: float = 0.8) -> List[str]:
        """
        Retrieve feedback สำหรับ Student
        - ดึง feedback ที่คล้ายกับ question นี้
        - Filter ด้วย similarity threshold
        """
        query_embedding = self.embedding_model.encode([question])[0]
        
        # Search FAISS
        distances, indices = self.index.search(
            query_embedding.reshape(1, -1), 
            top_k
        )
        
        # Filter by threshold
        feedbacks = []
        for dist, idx in zip(distances[0], indices[0]):
            if dist >= threshold:  # Cosine similarity [0, 1]
                feedbacks.append(self.memory_store[idx]["feedback"])
        
        return feedbacks
    
    
    def retrieve_for_teacher(
        self, 
        question: str, 
        student_answer: str,
        top_k: int = 5, 
        threshold: float = 0.85
    ) -> Optional[dict]:
        """
        Retrieve previous feedback สำหรับ Teacher (เพื่อ refine)
        - ดึง feedback เก่าที่เคยใช้กับ question คล้ายๆ
        - ถ้าเจอ feedback ที่ similar มาก (>0.95) = ใช้ซ้ำเลย
        - ถ้า similar ปานกลาง (0.85-0.95) = ดึงมาเป็น context สำหรับ COT
        """
        query_embedding = self.embedding_model.encode([question])[0]
        
        distances, indices = self.index.search(
            query_embedding.reshape(1, -1), 
            top_k
        )
        
        # Case 1: Very similar (>0.95) → Reuse exact feedback
        if distances[0][0] >= 0.95:
            exact_match = self.memory_store[indices[0][0]]
            return {
                "type": "reuse",
                "feedback": exact_match["feedback"],
                "similarity": distances[0][0]
            }
        
        # Case 2: Similar (0.85-0.95) → Use as context for COT refinement
        similar_feedbacks = []
        for dist, idx in zip(distances[0], indices[0]):
            if dist >= threshold:
                similar_feedbacks.append({
                    "feedback": self.memory_store[idx]["feedback"],
                    "similarity": dist,
                    "success_rate": self.memory_store[idx].get("success_rate", 0.0)
                })
        
        if similar_feedbacks:
            return {
                "type": "refine",
                "context": similar_feedbacks
            }
        
        # Case 3: No similar feedback → Generate new
        return {
            "type": "generate_new"
        }
```

### ⚠️ Issue 2: **Duplicate Questions with Different Phrasings**

**ปัญหา:**
```python
# คำถามเหล่านี้คล้ายกันมาก แต่ embedding อาจจะไม่เหมือน 100%
"Separate: helloworld"
"Split the word: helloworld"
"Break apart: helloworld"
```

**แนวทาง: Deduplication ด้วย High Similarity**
```python
def store_feedback(self, question: str, feedback: str):
    """
    ก่อน store ใหม่ → ตรวจสอบว่ามี question คล้ายๆ อยู่แล้วหรือไม่
    ถ้า similarity > 0.95 → Update แทนที่จะสร้างใหม่
    """
    query_embedding = self.embedding_model.encode([question])[0]
    
    # Search existing
    if len(self.memory_store) > 0:
        distances, indices = self.index.search(
            query_embedding.reshape(1, -1), 
            k=1
        )
        
        # ถ้าคล้ายมาก → Update
        if distances[0][0] >= 0.95:
            existing_idx = indices[0][0]
            self.memory_store[existing_idx]["feedback"] = feedback
            self.memory_store[existing_idx]["success_count"] += 1
            logger.info(f"Updated existing feedback (similarity={distances[0][0]:.3f})")
            return
    
    # ถ้าไม่คล้าย → Store ใหม่
    self.memory_store.append({
        "question": question,
        "feedback": feedback,
        "embedding": query_embedding,
        "success_count": 1,
        "fail_count": 0
    })
    self.index.add(query_embedding.reshape(1, -1))
```

### ⚠️ Issue 5: **Memory Size Explosion**

**ปัญหา:**
- Dataset 1000 questions → อาจจะมี 1000 feedback records
- FAISS index ใหญ่มาก, slow retrieval

**แนวทาง: Consolidation & Pruning**
```python
def consolidate_memory(self, similarity_threshold: float = 0.90):
    """
    รวม feedback ที่คล้ายกันมากๆ (>0.90)
    - ใช้ feedback ที่ success_rate สูงกว่า
    - ลบ feedback ที่ fail_count สูงเกินไป
    """
    # Group similar feedbacks
    groups = self._cluster_similar_feedbacks(similarity_threshold)
    
    # Keep best from each group
    consolidated = []
    for group in groups:
        best = max(group, key=lambda x: x["success_count"] / (x["success_count"] + x["fail_count"] + 1))
        consolidated.append(best)
    
    # Rebuild index
    self.memory_store = consolidated
    self._rebuild_index()
```

## 3. สรุปข้อควรระวัง

| Issue | Impact | Solution |
|-------|--------|----------|
| **Threshold mismatch** | Student ได้ feedback ไม่ตรง, Teacher reuse ผิด | ตั้ง threshold แยกกัน (0.8 vs 0.95) |
| **Duplicate questions** | Memory bloat, redundant storage | Deduplication ด้วย similarity >0.95 |
| **Cold start** | Student ไม่มี feedback ตอนเริ่ม | Seed memory ด้วย common feedbacks |
| **Stale feedback** | Retrieve feedback เก่าที่ไม่ effective | Filter by success_rate >0.6 |
| **Memory explosion** | Slow retrieval, high storage | Consolidate + prune low-performing feedbacks |
| **Cross-domain confusion** | Feedback ของ domain A ไปปนกับ B | Add question_type tag for filtering |
