# T0.2 — `.claude/` Environment Audit (is the crew fit for the new direction?)

- **Phase:** P0 (read-only) · **Owner:** main thread (archetype R) · **Depends on:** none
- **Output:** `docs/audit/CLAUDE_ENV_AUDIT.md`

## Objective
Audit the entire Claude environment — agents, rules, skills, guard, settings — against the NEW
project direction, and produce a findings report (BLOCKER/MAJOR/MINOR) that T1.6 will fix.

## Why (hub context)
The user asked directly: "does the crew understand the system and its jobs? Is the environment
designed so agents work at full efficiency?" The `.claude/` setup was designed around the
dataset-cleaning workstream, which is FINISHED. The project now pivots to: honest Track-A
ablation → RAG+LoRA product (3B floor / 7B ceiling) → eventually a user-facing app.

## Read first
- All of `.claude/`: `CLAUDE.md`, `rules/*.md`, `agents/*.md`, `skills/*/SKILL.md`,
  `hooks/guard.py`, `settings.json`
- `docs/plan/README.md` + T1/T2 spec titles (the work the crew must be able to execute)

## Steps
1. Per agent file: does its Identity/Must-read/Procedure/Output-contract (ADR-008) still point
   at real files and the current direction? Flag stale references and stale priorities.
2. Coverage matrix: for each upcoming task type (audit, config contract, eval design, memory
   design, prompt curation, loop rebuild, RAG, LoRA/QLoRA training, statistics/CI analysis,
   frontend later) — which agent owns it? Mark gaps (expected: no owner for LoRA training,
   RAG retrieval, statistical analysis of ablations).
3. Rules audit: which parts of `todo.md`, `structure.md`, `schema.md`, `providers.md` are
   stale vs the new plan? (Don't fix — list.)
4. Guard/skills/settings audit: do the guard regexes and permission denies still match the
   planned tree (e.g. new `experiments/`, `db/` dirs)? Do skills still run?
5. Rate FINDINGS: BLOCKER (will break P1/P2 work), MAJOR (wrong/missing ownership), MINOR.

## Definition of Done
- Findings list with severity + evidence (file:line) + NOT-VERIFIED section.
- A concrete recommendation table for T1.6: per agent → keep / update / add-new-role.

## Must NOT do
- No edits to `.claude/` (that is T1.6). No code changes.
