# T2.3 — Evaluation Block (correctness ≠ reference-match, enforced)

- **Phase:** P2 (code) · **Owner:** qa-engineer + prompt-engineer · **Depends on:** T2.2, EVAL_SPEC (T1.4), gate decisions
- **Output:** evaluation module (judge + diagnostics) + leakage tests + calibration probe results

## Objective
Implement EVAL_SPEC.md exactly: an independent correctness judge that decides pass/fail, and
reference-match diagnostics reported in a separate column — with tests proving the student/judge
path cannot see ground truth.

## Why (hub context)
This block is WHY Track A exists. The old evaluator mixed reference-proximity into the pass
decision (~65-75% weight) → inflated results. The two numbers must never be merged again.

## Read first
- `docs/plan/EVAL_SPEC.md` (the spec — implement, don't redesign) + gate decisions on student/judge
- `docs/LEAKAGE_AUDIT.md` (SCORE-PATH seals assigned to this task)
- `src/simplified/metrics.py` + `src/eval/metrics.py` (salvage primitives: rouge, semantic sim)

## Steps
1. `Judge` implementation per spec (blind rubric prompt, score parsing, retry/error policy);
   register in JudgeRegistry. Judge model/config from slot F only.
2. Diagnostics: reference_match (semantic + ROUGE vs reference) computed AFTER the pass/fail
   verdict, stored in separate fields; no weight, no threshold.
3. **Leakage tests (from census):** construct an evaluator, assert GT never appears in any
   prompt sent on the correctness path (intercept/inspect outgoing prompts in tests);
   config validator already blocks same-family judge — add an integration test.
4. Calibration probe per spec (GOOD/WRONG/TRUNCATED set): run it, report discrimination
   numbers as evidence; if the judge can't separate GOOD from WRONG → NEEDS-HUB-DECISION, stop.
5. Unit tests for parsing edge cases (judge returns prose, empty, out-of-range).

## Definition of Done
- Judge + diagnostics pass tests; calibration numbers reported honestly (§0.1) even if bad.
- Grep-proof: no `ground_truth` identifier in the correctness-path code, only in diagnostics.

## Must NOT do
- No combined/hybrid final score. Don't tune judge prompts against held-out data (calibration
  probe uses its own tiny set). Don't touch the legacy evaluator.
