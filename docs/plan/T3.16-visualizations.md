## Steps
1. One script (`scripts/make_figures.py` or a `reports/` notebook cell) that loads committed logs and
   emits each figure to `reports/figures/` (PNG for docs + SVG where useful; theme-legible).
2. Apply the `dataviz` skill: one consistent palette, accessible in light and dark, honest axes
   (no truncated baselines that exaggerate effects — §0.1 applies to charts too).
3. Caption each figure with its source (which run/analysis produced it).

## Definition of Done
- 5–6 figures in `reports/figures/`, regenerable by one command from logs; consistent style;
  captions cite sources; no number that isn't in a log.

## Must NOT do
- No hand-entered numbers (regenerate from logs). No misleading axes/truncation (honest viz, §0.1).
  Don't over-produce 20 charts — a tight set that carries the narrative.
