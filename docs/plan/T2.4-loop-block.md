# T2.4 — Loop Block v2 (clean minimal loop, arms as strategies)

- **Phase:** P2 (code) · **Owner:** codebase-steward + prompt-engineer · **Depends on:** T2.2, T2.3, T2.5
- **Output:** loop module with arm strategies A/B/C/D + tests

## Objective
Rebuild the teaching loop as a small, readable orchestrator: pick arm strategy from config
slot E, run rounds, delegate scoring to the eval block and remembering to the memory block.
Target: the core loop readable in one screen, not 843 lines.

## Why (hub context)
The legacy `run()` interleaves prompting, scoring, memory, logging, early-stop, and THREE
ground-truth escape hatches. Track A needs a loop where every arm is honest by construction
and adding an arm = adding a strategy class (Lego principle).

## Read first
- `simplified_teaching_loop.py` (what to salvage: round bookkeeping, early-stop idea; what to
  kill: LAST_CHANCE paths — see census)
- `docs/LEAKAGE_AUDIT.md` (STUDENT-VISIBLE seals assigned here)
- EVAL_SPEC arms table (T1.4) · PROMPT_CATALOG survivors (T1.5) · interfaces (T2.2)

## Steps
1. `ArmStrategy` implementations:
   - **A baseline:** 1 round, no feedback, no memory.
   - **B self-refine:** student self-critique preset between rounds; no teacher calls.
   - **C blind-teacher:** teacher feedback WITHOUT GT in its prompt; memory notes per T1.3.
   - **D sighted-teacher:** teacher sees GT (its prompt only), clearly labeled leakage-ceiling.
2. Loop core: rounds ≤ max_rounds, stop on judge pass or simple patience rule (port the
   early-stop concept, simplified; no GT-hint fallback — that path does not exist in v2).
3. **Leakage seals as tests:** for arms A/B/C assert the student-bound and judge-bound prompts
   never contain the reference (string + high-similarity check); arm D asserts GT appears ONLY
   in teacher-bound prompts.
4. Structured per-round logging compatible with schema.md experiment shapes (one logger, not four).
5. Unit tests with a mocked student/teacher/judge (no API calls) covering each arm's call pattern
   (B: zero teacher calls; A: exactly one student call; etc.).

## Definition of Done
- 4 arms selectable purely via config; mock-based tests prove call patterns + leakage seals;
  every census STUDENT-VISIBLE item has a corresponding test or is structurally impossible
  (function no longer exists) — state which, per item.

## Must NOT do
- No ground-truth hint mechanism in ANY form (not even config-gated). Don't modify the legacy
  loop (it stays for comparison until T2.9). Don't exceed the eval block's API (no scoring here).
