# T2.9 — Demolition (remove the dead wing, now that the new one stands)

- **Phase:** P2 (cleanup) · **Owner:** codebase-steward + housekeeping · **Depends on:** T2.8 done
  (new blocks proven by a full real run)
- **Output:** clean tree matching structure.md v2 + updated CODE_MAP + commit(s)

## Objective
Delete/archive everything CODE_MAP marked DEAD plus the superseded legacy core, so the repo a
newcomer clones contains one obvious way to run things.

## Why (hub context)
Strangler pattern's last step. We deliberately did NOT delete earlier: the legacy loop was the
only working system until T2.7 proved the new one on a full run. Now dead code is risk+confusion.

## Read first
- `docs/audit/CODE_MAP.md` demolition table (T0.1) · structure.md v2 placement/migration policy
- T2.8 completion evidence (the precondition — verify before deleting anything)

## Steps
1. Verify precondition: full Track-A run completed on the NEW stack (T2.7/T2.8 outputs exist).
2. Delete confirmed-dead files (retrieval.py, reports.py, prompts/teacher.py, logger_manager,
   console_logger + anything else CODE_MAP proved dead). Git history preserves them — delete,
   don't comment-out.
3. Legacy core (`simplified_teaching_loop.py`, `simplified_experiment_runner.py`,
   `src/simplified/*`): per structure.md v2 policy — expected: move to `archive/legacy/` or
   delete outright (git keeps it). If the policy is ambiguous → NEEDS-HUB-DECISION.
4. Prompt graveyard: apply T1.5 verdicts — survivors into the new preset layout, losers to archive.
5. Fix stragglers: `data/medical_all_clean.jsonl` misnomer, root-level junk, `__pycache__`
   gitignore gaps (from CODE_MAP/junk checklist).
6. `logs/experiments/` is IMMUTABLE evidence — touch nothing there, including
   `gt_memory_store.jsonl` (it documents the old flaw; the report cites it). Add a README
   marker in `docs/` noting its historical status if helpful.
7. Re-run housekeeping audit; update CODE_MAP.md to the new reality; run the new stack's tests
   one final time (evidence).

## Definition of Done
- Tree matches structure.md v2; tests green post-deletion; CODE_MAP updated; commits are
  reviewable (deletions separated from moves).

## Must NOT do
- Nothing in `data/` raw dirs or `logs/experiments/` gets deleted (guard + §evidence).
- No "while I'm here" refactors of live code — deletion only.
