# T2.6 — Runner + the Four Arm Configs ("one file to run, settings decide everything")

- **Phase:** P2 (code) · **Owner:** ops-engineer · **Depends on:** T2.1–T2.5
- **Output:** `run.py` (or per structure.md v2) + `experiments/trackA_arm{A,B,C,D}.yml` + dry-run evidence

## Objective
The single entrypoint the user asked for: `run.py --config experiments/trackA_armC.yml` composes
student/teacher/preset/memory/params/eval from registries and executes the experiment with full
structured logging. Prove it with a dry run.

## Why (hub context)
User's exact wish: "เรา run ไฟล์นี้แล้ว เราก็มี setting A(Student) B(teacher) C(preset)
D(memory) E(parameter)... แค่ไปปรับว่าจะใช้อะไร". This is the composition root — the only
place that assembles blocks; blocks never construct each other.

## Read first
- All P2 block interfaces (T2.1–T2.5 outputs) · schema.md experiment-summary shape
- `simplified_experiment_runner.py` (salvage: dataset loading with multi-schema fallback,
  progress UX ideas — keep it simpler)

## Steps
1. Runner: load+validate config → build blocks via registries → iterate questions from the
   configured dataset (held-out file for real runs) → write per-round JSONL +
   `summary.jsonl` per schema.md → print honest summary (correctness AND reference-match
   as separate columns, never merged).
2. Determinism (§0.3): seed everything seedable; record resolved config + seed + git commit
   into the run's output dir; runs land under the structure.md v2 location (NOT inside
   `logs/experiments/` legacy evidence dirs — those are immutable).
3. Write the 4 arm configs, minimal overrides over base.yml, using gate-decided student/judge.
4. **Dry run:** arms A + C, n=5 questions from the TRAIN split (never held-out for smoke tests),
   1 seed. Verify: logs complete, no crashes, judge returns sane verdicts, arm B/D configs at
   least parse + build.
5. Document usage in the runner docstring + a short `experiments/README.md`.

## Definition of Done
- One command runs any arm; dry-run outputs attached as evidence; summary lines match
  schema.md; §0.5 python path used throughout.

## Must NOT do
- No held-out data in smoke tests (§0.2). No hardcoded models/paths (config only).
  Don't delete legacy runners yet.
