# T3.5 — RAG Ablation Run + Honest Report → GATE ✋

- **Phase:** P3-A (execution + analysis) · **Owner:** ops-engineer + qa-engineer · **Depends on:** T3.2, T3.3, T3.4
- **Output:** run outputs + `docs/RAG_RESULTS.md` + ADR verdict. **Ends at a hub gate.**

## Objective
Run the pre-registered RAG ablation and report whether RAG closes the small-model gap:
**does 3B+RAG match or beat 3B (and approach 7B)?** — with the same honesty bar as Track A.

## Why (hub context)
This number decides the entire P3-B (LoRA) scope: if 3B+RAG already reaches the quality target,
LoRA is a thin style layer; if not, LoRA (and model-size) choices change. Measure before building
more — the discipline that made Track A trustworthy.

## Read first
- `docs/plan/RAG_SPEC.md` §pre-registered headline (T3.1) · `docs/TRACK_A_RESULTS.md` (comparison baseline)
- T3.2 index build report · T3.3/T3.4 outputs · `providers.md` (judge budget)

## Steps
1. Pilot (n≈25 train) across the 4 arms {3B, 3B+RAG, 7B, 7B+RAG} — mechanics + retrieval quality
   sane, judge behaving, held-out-exclusion holding. Go/no-go before full run.
2. Full run: held-out 125 × 4 arms × 3 seeds {13,42,123}, same blind judge as Track A.
3. Analysis (reuse `src/tlw/analysis`): per-arm correctness pass-rate (Wilson), headline
   **(3B+RAG)−3B** with 95% CI + McNemar; also (7B+RAG)−7B and 3B+RAG vs 7B (does RAG let the
   small model reach the big one?); faithfulness + reference_match as diagnostics.
4. `docs/RAG_RESULTS.md`: methods (link RAG_SPEC), headline table, does-RAG-close-the-gap verdict,
   limitations (single domain, judge validity, retrieval quality), honest comparison to Track A.
5. Run `reconcile-numbers`; every number traces to a run log (§0.1). ADR: "RAG result + P3-B implication".

## Definition of Done
- Pilot go-decision recorded; full run complete for every arm×seed; RAG_RESULTS.md reproducible
  from logs; reconcile-numbers passes; ADR logged.
- **GATE ✋:** return to the hub with RAG_RESULTS.md to scope P3-B (LoRA). Do NOT start T3.6 before this.

## Must NOT do

  as the headline (correctness is). Don't auto-start LoRA — the gate decides its scope.
