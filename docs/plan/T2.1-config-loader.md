# T2.1 — Config Loader + Validation (Contract v1 becomes code)

- **Phase:** P2 (code) · **Owner:** ops-engineer or codebase-steward · **Depends on:** P1 gate ✋ passed
- **Output:** config loader module in the new core package (location per structure.md v2) + tests + `config/base.yml`

## Objective
Implement the six-slot Config Contract: layered loading (base.yml + experiment override + env),
strict validation that fails loudly, and typed access for the other blocks.

## Why (hub context)
Config drift caused real damage (weights comment vs values mismatch, threshold under wrong
slot). Validation turns §0.2/§0.3 from prose into machine-enforced rules — the first Lego block
everything else plugs into.

## Read first
- schema.md "Experiment Config Contract v1" (T1.1 — the spec; do not deviate silently)
- structure.md v2 (where the module lives) · `config/simplified_config.yml` (legacy source of defaults)

## Steps
1. Create `config/base.yml` per contract — port current sane defaults; every default exists
   exactly once, no duplicated comments-as-docs.
2. Loader: deep-merge base → experiment file → env overrides; reject unknown keys; return a
   typed object (dataclasses fine — stdlib-first unless P1 chose otherwise).
3. Validators (each = its own test): eval weights sum to 1.0±ε; judge family ≠ student family
   (family map from `providers.md`); seed required; memory type ∈ registry; paths resolved
   project-relative (kills hardcoded absolute paths).
4. Tests under `tests/` mirroring src (first residents of the planned dir).
5. Run tests with tlw python (§0.5); paste output as evidence.

## Definition of Done
- Loader + base.yml + passing tests; a deliberately-broken config produces a clear, named error
  for each validation rule (show all failure messages in evidence).
- Legacy code untouched and still running.

## Must NOT do
- Don't port the legacy config bugs into base.yml (fix values, note them). Don't wire the
  legacy loop to the new loader (strangler: new runner only, T2.6). No heavyweight config
  frameworks unless P1 decided so.
