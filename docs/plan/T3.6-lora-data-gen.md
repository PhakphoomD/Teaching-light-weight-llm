# T3.6 — LoRA Data Generation via the Loop-Factory (LIGHT SPEC — firm up after T3.5 gate)

- **Phase:** P3-B (code) · **Owner:** data-engineer · **Depends on:** T3.5 gate ✋
- **Output:** curated LoRA training set (instruction/response pairs) + provenance

## Objective
Use the loop as the offline FACTORY it was proven to be (ADR-024): generate and curate
high-quality (question → grounded, well-styled answer) pairs for LoRA fine-tuning — teaching the
3B the *answer style* that self-refinement produced, so it needs fewer rounds at inference.

## Why (hub context)
Track A showed self-refine gives +9pt but costs extra rounds; LoRA can bake that style into the
weights (LIMA: fine-tuning teaches format/style, not facts). RAG (T3.3) supplies facts; LoRA
supplies delivery. This is the loop finally earning its keep — as a data generator, not a runtime.

## Read first (do this AFTER the T3.5 gate — scope may change)
- `docs/RAG_RESULTS.md` + its ADR (did RAG close the gap? that scopes what LoRA must add)
- `docs/TRACK_A_RESULTS.md` (self-refine is the behavior to distill) · `src/tlw/loop/`, `data/clean/` train

## Steps (provisional — the gate may adjust)
1. Generate answers on the TRAIN split via the best honest recipe (self-refine + RAG grounding);
   keep only answers that pass the blind correctness judge (quality gate).
2. Curate to a LIMA-scale set (~1k high-quality pairs; diversity over volume); dedup; NO held-out
   questions; record provenance (recipe, judge score, seed) per pair.
3. Format as an instruction-tuning dataset under `data/processed/`; write a data card.
4. Anti-leak: the set is built from TRAIN only; held-out stays untouched (§0.2).

## Definition of Done
- Curated pairs in `data/processed/` + data card + provenance; held-out-exclusion verified;
  reproducible generation command.

## Must NOT do
- Don't train on held-out. Don't skip the quality gate (a LoRA set of mediocre answers teaches
  mediocrity). Don't over-collect — LIMA says small+clean beats large+noisy. Re-read the gate
  outcome before deciding size/recipe.
