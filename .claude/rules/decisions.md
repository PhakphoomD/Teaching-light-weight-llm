## ADR-024 — Track-A verdict: the loop's benefit is self-refinement, not the teacher (2026-07-16) · Proposed
**Context:** T2.7 full pre-registered run (125 held-out Diabetes × 3 seeds {13,42,123}, student `qwen2.5:3b` local, blind judge Groq `llama-3.1-8b-instant` at PASS = score≥4, 4 arms A/B/C/D) — the honest answer to "does the teaching loop work?" (the question the renovation exists to settle, ADR-001).
**Decision (finding):** **C − B = +0.003, 95% CI [−0.021, +0.029], McNemar p = 1.00** → an independent teacher adds **nothing** over plain self-refinement. **B − A = +0.091, 95% CI [+0.051, +0.133], p < 0.0001** → self-refinement is a **real, significant** ~+9pt gain. Per-arm: A 0.821 / B 0.912 / C 0.915 / D 0.940 (D = leakage ceiling, 2 seeds; its seed-123 run aborted when `assert_gt_free` caught a real 12-token GT echo — the seal working). reference_match stayed flat (~0.69–0.72) as correctness rose → confirms ADR-019's split. This corrects ADR-001's inflated 25%→83%: the real iterate-gain is +9pt (self-refine), the rest was GT leakage.
**Implication (P3):** do NOT build a teacher-in-the-loop runtime improver; use self-refinement (free/local) + RAG (knowledge) + LoRA (style); the loop stays an **offline data/eval factory** — exactly ADR-003's thesis.
**Evidence:** `docs/TRACK_A_RESULTS.md` (full report); numbers computed live from `runs/trackA_full_arm{A,B,C,D}_diabetes__seed{13,42,123}__*/{summary,rounds}.jsonl` via `src/tlw/analysis/stats.py` (paired cluster bootstrap 10k resamples + exact McNemar + Wilson); judge 1656 calls 100% Groq / 0 fallback (consistent judge), teacher 175 calls 116,705 tok / 0 fallback.

## ADR-019 — Track-A eval protocol: blind correctness judge, C−B with CI (2026-07-13) · Accepted (P1 gate, ADR-022)
**Context:** Track A must answer one honest question — does independent teacher feedback beat self-retry? Old eval merged correctness with 70%-GT reference-match and leaked GT (ADR-001; LEAKAGE_CENSUS §2).
**Decision (lockable now):** (1) 4 arms A/B/C/D on the same held-out 125 (train 506 reserved), same 3 seeds; **D = labeled "leakage ceiling," not a result.** (2) Two never-merged metrics: `correctness` (blind LLM-judge 0–4, PASS ≥3) is the **headline**; `reference_match` (MiniLM + ROUGE-L) is a diagnostic column only (slot-F weights = {blind_score: 1.0}). (3) Judge is **blind** (Q+answer, no GT), family ≠ student family (§0.2, schema V2), judge ≠ teacher model, temp 0; validated on a GOOD/WRONG/TRUNCATED/PLAUSIBLE_WRONG calibration probe built on the **train** split before locking. (4) Pre-registered headline = **pass_rate(C) − pass_rate(B) with a 95% paired cluster-bootstrap CI** over the 125 questions (McNemar p-value alongside; Wilson per-arm descriptive). (5) Student runs **local** (free); teacher = Groq `qwen3-32b` (arms C/D only, ~3 days within caps); judge = **local** (Ollama, family≠student) with a Groq-70B **calibration-only** cross-check — a full Groq-70B judge pass is ~10× over its 100K TPD.
**Gate resolutions (ADR-022):** (a) student = **qwen2.5:7b-instruct local**; (b) **blind-only**; (c) **headline memory-off for all arms** — memory-on = separate C′/D′ ablation (memory effect = C′−C). Judge = local `llama3.1:8b`, probe-gated (ADR-022 (d)).
**Evidence:** LEAKAGE_CENSUS.md:50-76,118-167; ADR-001/002/011/014; providers.md caps; schema.md:71,87-111; tools/dataset/judge.py:24-47; scripts/compare_judges.py:1-45; split counts Grep→506/125.

## ADR-001 — Original results are inflated; model is not the bottleneck (2026-07-10) · Accepted
Reported "25%→83%" ≠ committed logs (33%→84%). Metric measures similarity to a noisy reference, not correctness; teacher sees GT every round (guided imitation); "100%" (P6C) = memorization. Baseline Llama-3.1-8B already answers well. Root cause = loop design + evaluation + dataset quality. TinyLlama fails on capability floor, not concept.
